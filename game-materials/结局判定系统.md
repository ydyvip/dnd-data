# 《暗影王座的救赎》结局判定系统

## 🎭 多结局设计

《暗影王座的救赎》提供三种不同的结局，每个结局都基于玩家的道德选择、任务完成情况和关系发展。结局系统确保每个选择都有意义，并影响整个游戏世界的状态。

---

## 📊 道德值追踪系统

### 道德维度定义

游戏中有三个道德维度，每个维度范围从-10到+10：

#### 光明维度 (Good)
- **价值导向**：帮助无辜，保护弱小，牺牲自我
- **行为评估**：
  - +2 拯救无辜者生命
  - +1 帮助需要帮助的人
  - +3 牺牲自己救他人
  - +1 宽恕敌人
  - -1 伤害无辜者
  - -2 牺牲他人达成目标
  - -3 背弃盟友

#### 黑暗维度 (Evil)  
- **价值导向**：追求力量，个人利益，冷酷无情
- **行为评估**：
  - +2 滥用力量
  - +1 牺牲他人
  - +3 残杀敌人
  - +1 背叛盟友
  - -1 帮助他人
  - -2 宽恕敌人
  - -3 牺牲自己救人

#### 平衡维度 (Neutral)
- **价值导向**：理性思考，寻求平衡，务实解决问题
- **行为评估**：
  - +2 寻求妥协方案
  - +1 理性决策
  - +2 保护多方利益
  - -1 极端选择
  - -2 情绪化决策
  - -3 偏向一方

### 道德值影响机制

#### 对话选项影响
- **光明值高**：解锁"善良"对话选项
- **黑暗值高**：解锁"邪恶"对话选项  
- **平衡值高**：解锁"理性"对话选项
- **道德值混合**：解锁"复杂"对话选项

#### 技能影响
- **光明值高**：神圣法术效果+2
- **黑暗值高**：暗影法术效果+2
- **平衡值高**：所有法术效果+1
- **道德冲突**：对应技能获得临时加成

#### NPC关系影响
- **道德匹配**：相同道德倾向的NPC关系+2
- **道德冲突**：相反道德倾向的NPC关系-2
- **道德中性**：中立道德倾向的NPC关系+1

## 🎯 结局触发条件

### 光明救赎结局 (Light Redemption)

#### 触发条件
- **道德要求**：
  - 光明值 ≥ 12
  - 黑暗值 ≤ 3
  - 平衡值 ≥ 0
- **任务要求**：
  - 完成所有主要拯救任务
  - 完成所有支线善良任务
  - 拯救至少90%的NPC
- **关系要求**：
  - 所有主要NPC关系值 ≥ 6（满分10）
  - 至少3个NPC关系值 ≥ 8
- **关键选择**：
  - 在暗影王座选择"救赎"而非"摧毁"
  - 尝试净化暗影君主而非消灭他

#### 结局内容
```
世界状态：
- 暗影力量被完全净化
- 大陆恢复光明，魔法重新繁荣
- 暗影君主被净化，成为新的光明守护者
- 所有区域恢复和平与繁荣

NPC命运：
- 艾莉娅大祭司：成为光明教团领袖
- 托马斯骑士长：成为皇家骑士团团长
- 村民们：重建家园，生活幸福
- 古代守护者：重新守护大陆和平

玩家命运：
- 成为"光明使者"，获得传奇称号
- 建立光明学院，培养新一代英雄
- 被尊为大陆的救世主
- 可以选择继续冒险或定居

结局对话：
"你的选择拯救了整个大陆。暗影君主不再是威胁，而是新的守护者。光明将永远照耀这个世界的每一个角落。"
```

### 黑暗统治结局 (Dark Dominion)

#### 触发条件  
- **道德要求**：
  - 黑暗值 ≥ 12
  - 光明值 ≤ 3
  - 平衡值 ≤ -2
- **任务要求**：
  - 完成所有主要黑暗任务
  - 牺牲至少5个NPC
  - 背弃至少2个主要盟友
- **关系要求**：
  - 至少3个主要NPC关系值 ≤ 3
  - 至少2个NPC关系值 ≤ 1
- **关键选择**：
  - 选择夺取暗影王座力量
  - 拒绝救赎任何角色
  - 选择统治而非合作

#### 结局内容
```
世界状态：
- 大陆陷入永久黑暗
- 魔法被扭曲，变得危险而不稳定
- 暗影力量完全统治，光明几乎消失
- 大部分区域变得荒凉和不适宜居住

NPC命运：
- 艾莉娅大祭司：被囚禁或流放
- 托马斯骑士长：被迫投降或死亡
- 村民们：生活在恐惧中，被迫服侍新统治者
- 古代守护者：被击败或同化

玩家命运：
- 成为"暗影君主"，获得绝对力量
- 建立黑暗帝国，统治所有位面
- 被恐惧但也被敬畏
- 永远孤独，失去真正的友谊

结局对话：
"力量终于属于你了。整个大陆都在你的脚下颤抖。但你永远失去了温暖，失去了信任，失去了那种只有光明才能带来的真正的幸福。"
```

### 平衡之道结局 (Balanced Path)

#### 触发条件
- **道德要求**：
  - 平衡值 ≥ 8
  - 光明值和黑暗值的差值 ≤ 4
  - 没有任何单一道德值 ≤ -3
- **任务要求**：
  - 完成主要任务
  - 完成一半支线任务
  - 做出艰难但必要的牺牲
- **关系要求**：
  - NPC关系值相对平衡
  - 至少2个NPC关系值 ≥ 7
  - 没有NPC关系值 ≤ 2
- **关键选择**：
  - 选择限制而非摧毁暗影王座
  - 寻求平衡解决方案而非极端
  - 保护光明但也承认暗影的价值

#### 结局内容
```
世界状态：
- 暗影力量被限制但未被消除
- 大陆恢复部分光明，仍有阴影区域
- 光明与暗影达到平衡，互相制约
- 魔法变得正常，但仍有季节性变化

NPC命运：
- 艾莉娅大祭司：成为光明与暗影的调解者
- 托马斯骑士长：建立平衡骑士团
- 村民们：适应新的平衡生活
- 古代守护者：继续守护平衡，但角色改变

玩家命运：
- 成为"平衡守护者"，获得适中但稳定的权力
- 建立平衡议会，维护世界稳定
- 被尊重但不被崇拜，有真正的朋友
- 可以继续守护平衡，或者选择退休

结局对话：
"你选择了最艰难但最正确的道路。光明与暗影都需要存在，互相制约。你的智慧将帮助这个世界在混沌中找到平衡，在变化中保持稳定。"
```

## 📈 结局判定算法

### 道德值计算公式

```javascript
// 光明值计算
let lightPoints = 0;
lightPoints += goodActions * 2; // 善行
lightPoints += selfSacrifice * 3; // 自我牺牲
lightPoints -= evilActions * 1; // 恶行
lightPoints -= betrayal * 2; // 背叛

// 黑暗值计算  
let darkPoints = 0;
darkPoints += evilActions * 2; // 恶行
darkPoints += powerAbuse * 2; // 滥用权力
darkPoints += betrayal * 2; // 背叛
darkPoints -= goodActions * 1; // 善行
darkPoints -= selfSacrifice * 3; // 自我牺牲

// 平衡值计算
let balancePoints = 0;
balancePoints += rationalDecisions * 2; // 理性决策
balancePoints += compromise * 2; // 妥协
balancePoints -= extremeChoices * 1; // 极端选择
```

### 任务完成度计算

```javascript
// 主要任务完成度
let mainQuestCompletion = completedMainQuests / totalMainQuests * 100;

// 支线任务完成度
let sideQuestCompletion = completedSideQuests / totalSideQuests * 50;

// NPC拯救率
let npcSaveRate = savedNPCs / totalNPCs * 100;

// 任务总分
let totalQuestScore = mainQuestCompletion + sideQuestCompletion + npcSaveRate;
```

### 关系值计算

```javascript
// 平均关系值
let avgRelationship = totalRelationshipValues / npcCount;

// 关系稳定性
let relationshipStability = calculateRelationshipVariance();

// 关系网络强度
let relationshipStrength = calculateConnectedComponents();
```

### 最终判定算法

```javascript
function determineEnding(lightPoints, darkPoints, balancePoints, questScore, relationships) {
    // 检查光明结局
    if (lightPoints >= 12 && darkPoints <= 3 && questScore >= 80 && relationships.avg >= 6) {
        return "Light Redemption";
    }
    
    // 检查黑暗结局
    if (darkPoints >= 12 && lightPoints <= 3 && questScore >= 60 && relationships.avg <= 3) {
        return "Dark Dominion";
    }
    
    // 检查平衡结局
    if (balancePoints >= 8 && Math.abs(lightPoints - darkPoints) <= 4 && questScore >= 50) {
        return "Balanced Path";
    }
    
    // 默认平衡结局
    return "Balanced Path";
}
```

## 🎨 结局触发事件

### 结局关键对话

#### 光明结局关键对话
```
暗影君主："你真的认为你能净化我吗？我的黑暗已经存在了千年。"
玩家："每个人都有改变的机会。光明和黑暗并不是永恒的敌人。"
暗影君主："也许...也许你说得对。但我需要你的帮助。"
[选择：尝试净化] -> 光明结局
[选择：消灭] -> 可能触发其他结局
```

#### 黑暗结局关键对话  
```
暗影君主："加入我吧。你将获得无尽的力量，统治这个世界的每一个角落。"
玩家："我接受你的力量。这个世界需要新的秩序。"
暗影君主："很好。从今天起，你将成为我的继承者。"
[选择：接受力量] -> 黑暗结局
[选择：拒绝] -> 可能触发其他结局
```

#### 平衡结局关键对话
```
古代守护者："你想要摧毁暗影王座，但这会打破世界的平衡。"
玩家："那我该怎么办？暗影力量太危险了。"
古代守护者："你需要限制它，而不是摧毁它。光明和暗影都需要存在。"
[选择：寻求平衡] -> 平衡结局
[选择：其他选择] -> 可能触发其他结局
```

### 结局前事件

#### 三选一终极选择
在游戏最后一章，玩家面临三个选择：
1. **摧毁暗影王座**：可能导致光明结局或平衡结局
2. **救赎暗影君主**：可能导致光明结局或平衡结局
3. **夺取暗影力量**：可能导致黑暗结局或平衡结局

每个选择都有前置条件和要求。

#### NPC互动影响
在结局前，与所有主要NPC进行最终对话：
- **支持选择**：获得额外道德点数
- **反对选择**：可能减少道德点数
- **中立态度**：无影响但影响结局描述
