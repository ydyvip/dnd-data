# 《暗影王座的救赎》法术和技能手册

## 🔮 法术系统概述

### 法术类型分类
- **奥术法术**: 基于魔法知识的法术
- **神圣法术**: 基于信仰力量的法术
- **自然法术**: 基于自然力量的法术
- **暗影法术**: 基于暗影力量的法术
- **元素法术**: 基于元素力量的法术

### 法术等级系统
- **戏法** (0环): 无需法术位，每天可多次使用
- **术士法术** (1-4环): 基于角色等级，每天可使用有限次数
- **法师法术** (1-9环): 需要记忆，每天可使用有限次数
- **牧师法术** (1-9环): 基于信仰，每天可使用有限次数

### 法术准备系统
- **准备时间**: 每天需要1分钟准备法术
- **法术位**: 每天可使用的法术数量
- **法术记忆**: 需要记忆法术才能使用
- **法术恢复**: 每天休息后恢复法术位

## 🧪 技能树系统

### 技能点分配
- **初始技能点**: 1级角色获得5点技能点
- **等级提升**: 每升一级获得2点技能点
- **技能重置**: 可通过特殊方式重置技能点
- **技能上限**: 单个技能最高5级

### 技能解锁条件
- **基础技能**: 1级可学习
- **进阶技能**: 需要相关技能达到3级
- **精通技能**: 需要相关技能达到5级
- **传奇技能**: 需要完成特定任务
- **神话技能**: 需要达到特定道德值

### 技能组合效果
#### 战斗组合
- **剑术 + 格挡**: 防御姿态
- **弓术 + 潜行**: 伏击组合
- **双武器 + 爆发力**: 双持爆发

#### 法术组合
- **火系 + 风系**: 爆裂风暴
- **光明 + 暗影**: 阴阳调和
- **神圣 + 自然**: 自然神圣

#### 技能组合
- **潜行 + 暗影**: 完美隐身
- **治疗 + 净化**: 完全治愈
- **防御 + 反击**: 无敌防御
