# 《暗影王座的救赎》怪物图鉴

## 🐉 怪物系统概述

### 怪物分级系统
- **普通怪物 (CR 1-3)**: 新手等级，适合新手玩家
- **精英怪物 (CR 4-7)**: 进阶等级，需要一定装备和技能
- **首领怪物 (CR 8-12)**: 高级挑战，需要团队合作
- **传说怪物 (CR 13-17)**: 史诗挑战，需要精心准备
- **神话怪物 (CR 18+)**: 终极挑战，影响游戏结局

### 怪物元素类型
- **火系**: 火焰伤害，易受冰霜伤害
- **冰霜**: 冰霜伤害，易受火焰伤害
- **雷电**: 雷电伤害，易受土系伤害
- **毒素**: 毒素伤害，易受神圣伤害
- **暗影**: 暗影伤害，易受光明伤害
- **光明**: 光明伤害，易受暗影伤害
- **土系**: 土系伤害，易受雷电伤害
- **神圣**: 神圣伤害，易受暗影伤害
