### 急救剧情模板

#### 玩家偏离主线模板
```
触发条件：玩家选择意外的剧情方向

处理流程：
1. 承认选择："你们的选择很有趣，让我们看看..."
2. 快速重构："你们的选择导致了..."
3. 提供新目标："现在你们需要..."
4. 保持连贯："这让我们想起了之前提到的..."

示例：
玩家："我们不关心村民，我们要去森林寻找宝藏！"
GM："你们决定放弃村民，直接前往森林。在路上，你们发现了一个被遗弃的宝藏猎人营地，里面藏着关于暗影碎片的重要信息..."

保持游戏连贯性，同时尊重玩家选择。
```

#### 玩家角色死亡模板
```
处理流程：
1. 暂停游戏："让我们暂停一下，讨论角色的命运..."
2. 回顾战斗："回顾一下刚才的战斗，看看是否有遗漏..."
3. 提供选项：
   - 复活机会：通过特殊仪式或物品
   - 新角色创建：创建新角色加入团队
   - 临时角色：使用预备角色
4. 重新整合："新角色如何融入团队..."

示例：
战士角色在战斗中阵亡
GM："托马斯的牺牲令人惋惜，但他的精神将激励我们。玛丽亚可以通过神圣仪式尝试复活他，但这需要..."

处理要快速且尊重，避免游戏长时间停滞。
```

#### 玩家冲突模板
```
处理流程：
1. 私下沟通："我们需要谈谈角色之间的冲突..."
2. 寻找共同点："你们都有什么共同目标？"
3. 提供解决方案："也许你们可以..."
4. 设定界限："让我们确保游戏体验不受影响..."

示例：
两个玩家角色因为决策产生冲突
GM："我注意到你们在如何处理村民的问题上有分歧。也许我们可以找到一个两全其美的方案？毕竟保护村庄是你们共同的责任..."
```

### 战斗难度计算器

#### 难度计算公式

**基础难度** = 玩家平均等级 + 怪物CR - 环境加成 + 战术修正

#### 环境加成表

| 环境类型 | 攻击修正 | 防御修正 | 移动修正 | 特殊效果 |
|----------|----------|----------|----------|----------|
| 开放平原 | 0 | 0 | 0 | 无特殊 |
| 森林 | -1 | +1 | -5 | 远程攻击disadvantage |
| 高地 | +2 | -1 | 0 | 远程攻击+2 |
| 狭窄通道 | -1 | +1 | -10 | 近战攻击优势 |
| 水域 | -2 | -2 | -10 | 火系法术优势 |
| 室内 | 0 | +2 | -5 | 声音传播受限 |

#### 战术修正表

| 战术因素 | 修正值 | 说明 |
|----------|--------|------|
| 数量优势 | +1 | 每多一个盟友 |
| 装备优势 | +1-3 | 精良/稀有/传奇装备 |
| 技术优势 | +1 | 对抗特定敌人 |
| 位置优势 | +2 | 占据有利位置 |
| 状态优势 | +2 | 状态效果加成 |
| 玩家等级优势 | +1 | 每高一级 |

#### 难度等级判定

| 计算结果 | 难度等级 | 建议玩家等级 | 建议调整 |
|----------|----------|---------------|----------|
| -3或更低 | 极简单 | 低2-3级 | 增加敌人 |
| -1到-2 | 简单 | 低1-2级 | 保持现状 |
| 0 | 标准 | 相符 | 保持现状 |
| 1-2 | 困难 | 高1-2级 | 减少敌人 |
| 3或更高 | 极难 | 高3级+ | 大幅减少 |

## 🎯 实用GM工作流程

### 游戏前准备
1. **设定场景**：描述当前场景的5个关键元素
2. **确认目标**：明确当前章节的主要目标
3. **准备遭遇**：准备2-3个可能遭遇
4. **检查资源**：确认玩家当前状态和资源
5. **设定氛围**：准备背景音乐和描述词汇

### 游戏中管理
1. **节奏控制**：每30分钟检查一次游戏节奏
2. **玩家参与**：确保每个玩家都有参与机会
3. **规则应用**：准确应用规则，保持一致性
4. **即兴发挥**：根据玩家选择灵活调整
5. **氛围维持**：持续营造游戏氛围

### 游戏后总结
1. **回顾过程**：回顾游戏中的关键事件
2. **玩家反馈**：收集玩家反馈和建议
3. **调整计划**：根据反馈调整下次游戏计划
4. **记录进度**：记录游戏进度和重要事件
5. **准备下次**：为下次游戏做好准备

## 📊 快速决策工具

### GM决策流程
```
遇到问题 → 快速评估 → 选择方案 → 执行决定 → 观察效果 → 调整优化
```

### 常见问题处理
**玩家不活跃**
- 原因：角色不合适，参与感不强
- 解决：给予特殊角色任务，调整角色设定

**游戏进度缓慢**
- 原因：玩家犹豫，选择困难
- 解决：提供明确选项，设置时间限制

**规则争议**
- 原因：规则理解不一致
- 解决：暂时采用简化规则，游戏后详细讨论

**情绪波动**
- 原因：剧情影响，个人问题
- 解决：暂停游戏，私下沟通，调整内容
